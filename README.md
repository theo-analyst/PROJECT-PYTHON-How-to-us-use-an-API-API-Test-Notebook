# API Data Retrieval and Testing Project

## Overview
Developed Python scripts and a Jupyter Notebook to interact with APIs, retrieve data, and test API responses for analysis and reporting purposes.

## Features
- Connected to RESTful APIs using Python (`requests` library)
- Sent GET/POST requests and handled responses
- Parsed JSON and XML data into usable formats
- Performed data validation and error handling
- Tested API endpoints and documented results in a Jupyter Notebook
- Visualized API data for insights (optional)

## Skills Demonstrated
- API integration and interaction using Python
- JSON/XML parsing and data transformation
- Error handling and response validation
- Automation of API testing workflows
- Data analysis and visualization of API responses
- Documentation and reproducible notebooks

## Tools Used
- Python (requests, json, pandas)
- Jupyter Notebook
- Postman (optional, for manual API testing)
